# معمارية Maya — Z-Assistant (Windows/Android)

## نظرة عامة

```text
Flutter App (Windows / Android)
        ↓ HTTPS (نص فقط — لا صوت يُرفع)
Cloudflare Worker (backend/)
        ↓ مفتاح Gemini في Cloudflare Secrets
Gemini API — للمحادثة والنوايا غير المعروفة
        ↓ عند الفشل أو نفاد الحصة
Fallback محلي: الأوامر الآمنة المحددة تعمل بلا إنترنت
```

## الفصل الأساسي (لا يُخترق)

1. **التقاط الصوت** داخل الجهاز (منصة) — لا يُسجَّل ولا يُخزَّن.
2. **تحويل كلام → نص** محليًا على الجهاز.
3. **كشف اللغة واللهجة** محليًا (`language_detector.dart`).
4. **تحديد النية** أولاً بأول: محليًا (`offline_command_service.dart`) أو على الـ Worker (`intents.ts`) — القائمتان متطابقتان.
5. **الصلاحيات**: `permission_policy.dart` (safe / sensitive / critical-معطل).
6. **التنفيذ**: أفعال محددة عبر `platform_service.dart` بقوائم وسائط فقط — النص المنطوق لا يصل shell أبدًا.

## الأمان

- مفتاح Gemini في Cloudflare Secrets فقط؛ لا يوجد أي سر في Dart أو APK أو Git.
- الـ Worker يقفل النموذج على قائمة نيات بيضاء مع تحقق من المعطيات؛ أي نية مبتدعة تتحول إلى رد نصي دون تنفيذ.
- Rate limit يومي لكل IP + CORS مقصور + حدود حجم الجسم والنص.
- سقف تسجيل 12 ثانية، وحذف الملفات المؤقتة فورًا (`SessionTempFiles`).

## ملاحظات صادقة على v1

- التعرف الصوتي المحلي على Windows يحتاج جسرًا أصليًا (WinRT) — الواجهة جاهزة والتنفيذ لاحق؛ أندرويد يعمل الآن.
- عداد الطلبات داخل ذاكرة الـ isolate — للعدد العالمي الدقيق: Workers KV / Durable Object.
- أوامر sensitive التي تلمس بيانات خارجية (إرسال رسائل خارج التطبيق، تغيير إعدادات النظام) تمر بالتأكيد لكن منفذيها على الجهاز غير مفعّلين بعد — يُعلن ذلك للمستخدم.
- مصادقة critical (Windows Hello) معرفة كواجهة وTODO واضح دون تفعيل.

# Maya AI 1.2 — دعم العربية

أصبحت Maya تدعم الآن أوامر صوتية بالعربية والإنجليزية، مثل:

- **مايا، افتحي كروم**
- **افتح واتساب**
- **ابحث في جوجل عن Python**
- **ابحث في يوتيوب عن أخبار التقنية**
- **شغّل أغنية Believer**
- **افتح مجلد التنزيلات**
- **التقط صورة للشاشة**
- **عرّفي نفسك**
- **أوقف مايا**

## التشغيل

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

يلزم على macOS:

1. تثبيت [Ollama](https://ollama.com/).
2. تنزيل النموذج:

   ```bash
   ollama pull llama3
   ```

3. منح Python صلاحيات الميكروفون وتسجيل الشاشة عند طلب macOS.

يمكن تغيير نموذج Ollama عبر:

```bash
MAYA_OLLAMA_MODEL=llama3.2 python main.py
```

## كيف تعمل اللغات؟

- يستخدم التعرف الصوتي Google Speech Recognition ويحاول العربية (`ar-SA`) ثم الإنجليزية (`en-US`).
- يرد المساعد باللغة العربية عندما يحتوي الأمر على حروف عربية.
- صوت macOS العربي يعتمد على الأصوات المثبتة في الجهاز؛ إذا لم يتوفر صوت عربي فسيستخدم الصوت الافتراضي.

## حدود التنفيذ الآمن

لا تنفذ Maya نصًا صوتيًا عشوائيًا كأمر shell. الأوامر المعروفة تنفذ عبر استدعاءات منفصلة وآمنة، أما السؤال أو الأمر غير المعروف فيُرسل إلى Ollama للحصول على إجابة فقط. هذا يمنع تحويل نص من المستخدم أو من النموذج إلى أوامر خطرة على الجهاز.

## الحفاظ على الملفات

تُحفظ لقطات الشاشة داخل مجلد `screenshots/` بجانب المشروع، ولا يتم حذف أو استبدال ملفات المستخدم. صورة البداية تُفتح مباشرة من مسار المشروع دون كتابة مسارات خاصة بجهاز المؤلف.
